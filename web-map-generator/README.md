## V2 - 当前版本

直接在浏览器中打开 `v2/index.html`

### 核心算法

#### 岛屿生成 - 位置优先 + 碰撞检测

- **位置优先**：先确定岛屿位置（中心点），再生成地形
- **碰撞检测**：每个新岛屿检查与已有岛屿的最小距离，确保无重叠
- **三级降级策略**：空间不足时依次尝试：原始参数 → 缩小岛屿 → 放宽边界
- **独立岛屿**：岛屿之间不连接，每个岛屿是独立的地理单元

#### 特征生成 - 层级覆盖算法

- **层级顺序**：岛屿(Land) → 山峰(Mountain) → 湖泊(Lake) → 森林(Forest)
- **空间均匀分布**：使用网格哈希将岛屿划分为桶，每个桶选择一个特征点
- **遮罩填充**：只覆盖指定类型的单元格（如湖泊只覆盖普通陆地）

#### 岛屿/特征数量

- **范围随机数**：所有数量参数（岛屿、山峰、湖泊、森林）支持 min-max 范围形式
- **默认值**：上下界相同，保持固定数量行为
- **用户可调**：设置不同值实现随机数量

#### 地形类型

| 类型              | 颜色      |
| ----------------- | --------- |
| 空域 Air / Vacuum | `#1a1a2e` |
| 岛屿 Island       | `#d4a843` |
| 山峰 Mountain     | `#8b8b8b` |
| 湖泊 Lake         | `#3a8fd6` |
| 森林 Forest       | `#2d7a2d` |

#### 可调参数

- **数量范围 (min - max)**：岛屿、山峰、湖泊、森林
- **半径范围 (min - max)**：岛屿、山峰、湖泊、森林

## V1 - 旧版实现

直接在浏览器中打开 `v1/index.html`

### 核心算法

#### 岛屿生成 - 网格分区 + 碰撞检测

- **网格分区初始化**：将地图划分为网格单元，每个岛屿分配一个网格
- **随机偏移**：在网格内添加随机偏移增加自然感
- **碰撞检测**：每个新岛屿检查与已有岛屿的最小距离，确保无重叠
- **双重策略**：前20次尝试使用网格策略，后续完全随机放置
- **独立岛屿**：岛屿之间不连接，每个岛屿是独立的地理单元

#### 特征生成 - 层级覆盖算法

- **层级顺序**：岛屿(Land) → 山峰(Mountain) → 湖泊(Lake) → 森林(Forest)
- **空间均匀分布**：使用网格哈希将岛屿划分为桶，每个桶选择一个特征点
- **遮罩填充**：只覆盖指定类型的单元格（如湖泊只覆盖普通陆地）

#### 地形类型

| 类型          | 颜色      |
| ------------- | --------- |
| 海洋 Ocean    | `#1a1a2e` |
| 岛屿 Island   | `#d4a843` |
| 山峰 Mountain | `#8b8b8b` |
| 湖泊 Lake     | `#3a8fd6` |
| 森林 Forest   | `#2d7a2d` |

#### 可调参数

- **数量 (固定值)**：岛屿、山峰、湖泊、森林
- **半径范围 (min - max)**：岛屿、山峰、湖泊、森林
